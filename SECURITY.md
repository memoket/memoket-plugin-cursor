# Security Policy

This plugin retrieves private recording-derived content through Memoket OAuth.
Do not open a public issue containing a token, OAuth code, transcript, summary,
brief, participant information, or other personal data.

Report vulnerabilities through the contact channel published in the
[Memoket Trust Center](https://trust.memoket.ai/). Include the affected plugin
version, Cursor version, reproduction steps, and impact. Use synthetic data and
redact credentials and recording content.

Non-sensitive documentation and packaging bugs can be reported through
[GitHub Issues](https://github.com/memoket/memoket-plugin-cursor/issues).
