# Security Policy

This plugin retrieves private recording-derived content through Memoket OAuth.
Do not open a public issue containing a token, OAuth code, transcript, summary,
brief, participant information, or other personal data.

A verified private vulnerability intake is not currently published. Request a
secure reporting channel through the [official Memoket website](https://memoket.ai/)
without including vulnerability details, credentials, or recording content in
the initial message.

Once a secure channel is confirmed, include the affected plugin version, Cursor
version, reproduction steps, and impact. Use synthetic data and redact
credentials and recording content.

Non-sensitive documentation and packaging bugs can be reported through
[GitHub Issues](https://github.com/memoket/memoket-plugin-cursor/issues).
